# Free data sources and predictive evidence for common trading-bot signals (liquidations, Hyperliquid whales, OI, long/short ratio, options IV/skew, on-chain flows, Polymarket, order-book imbalance)

Research date: 2026-10-09. "Live probe" = I called the public endpoint read-only on 2026-10-09 and report what came back (the URL is the source). Everything else is cited to a docs page or paper. Where I could only see an abstract or a search snippet, I say so.

## 1. Free data availability, depth and exact endpoints (per source)

### Takeaway
Most useful free history is (a) Binance data.binance.vision daily `metrics` files (OI + long/short ratios, 5-minute rows, 2020-09 for BTC, 2021-12 for alts), (b) Deribit DVOL daily from 2021-03-24 and options trades with IV back to at least 2022 via history.deribit.com, (c) Hyperliquid funding history and daily candles (but only about the last 5000 candles per interval, so 1h reaches back ~6 months), (d) DefiLlama aggregate stablecoin supply from 2017-11, (e) Polymarket price history per outcome token. Liquidation history is forward-only on every venue I checked (no Binance liquidationSnapshot prefix exists any more; OKX returns only recent liquidations). Hyperliquid whale/position history is not available from the info API; it needs the requester-pays S3 archive or forward collection.

### Cited Findings

**Hyperliquid (info API, free, no key)**
- All info requests are `POST https://api.hyperliquid.xyz/info`. Perp request types include `meta`, `metaAndAssetCtxs` (mark price, funding, open interest in the asset context), `fundingHistory` (coin, startTime required, endTime optional, both ms, inclusive), `predictedFundings`, `userFunding`, `perpsAtOpenInterestCap`. There is no separate `openInterest` request type; OI appears only as a field of `metaAndAssetCtxs`, i.e. a current snapshot, not history. The page states no record caps or max history depth for fundingHistory — [Hyperliquid docs: perpetuals info](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals)
- `candleSnapshot` (body: `{"type":"candleSnapshot","req":{"coin","interval","startTime","endTime"}}`): "Only the most recent 5000 candles are available." Intervals: 1m,3m,5m,15m,30m,1h,2h,4h,8h,12h,1d,3d,1w,1M. `userFills` returns at most 2000 recent fills; `userFillsByTime` only the 10000 most recent fills — [Hyperliquid docs: info endpoint](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint)
- Live probe, fundingHistory BTC from 2023-05-01: returned 500 records per call (2023-05-12 to 2023-06-25 in the first page, hourly), so history must be paginated forward by advancing startTime; first record available was 2023-05-12 for that query — [POST /info fundingHistory](https://api.hyperliquid.xyz/info)
- Live probe, candleSnapshot BTC 1d from 2022-01-01 returned 1725 candles starting 2022-01-01 (daily depth is fine because 5000 days is >13 years); the same request at 1h returned only 4585 candles starting 2026-03-14, i.e. about 6 months of hourly bars — [POST /info candleSnapshot](https://api.hyperliquid.xyz/info). A third-party guide notes pre-launch candles (before roughly April 2023) are zero-volume backfilled price data (unverified by docs) — [OneKey guide](https://onekey.so/blog/ecosystem/hyperliquid-historical-data-api/)
- Bulk history: AWS S3 `hyperliquid-archive` (L2 book snapshots `market_data/[date]/[hour]/l2Book/[coin].lz4`, and `asset_ctxs/[date].csv.lz4` which carry funding/OI contexts) and `hl-mainnet-node-data` (`node_fills_by_block`, `explorer_blocks`, `misc_events_by_block`). Requester pays transfer cost (`--request-payer requester`); docs say uploads are roughly monthly, "no guarantee of timely updates and data may be missing"; no start dates given — [Hyperliquid docs: historical data](https://hyperliquid.gitbook.io/hyperliquid-docs/historical-data). This needs an AWS account with billing, so it is not "free, no-signup".
- A public leaderboard file exists: live probe of `https://stats-data.hyperliquid.xyz/Mainnet/leaderboard` returned HTTP 200, ~38.6 MB (this is a current snapshot of account-level PnL stats, not position history; I did not inspect the schema) — [leaderboard URL](https://stats-data.hyperliquid.xyz/Mainnet/leaderboard)
- Per-wallet positions: `clearinghouseState` takes a user address and returns the current perp account summary; per-user history is capped by the fill limits above — [Hyperliquid docs: perpetuals info](https://hyperliquid.gitbook.io/hyperliquid-docs/for-developers/api/info-endpoint/perpetuals)

**Binance (data.binance.vision bulk files and live API)**
- Bulk bucket listing (public S3 index): `https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=data/futures/um/daily/`. Live probe on 2026-10-09 shows USD-M daily prefixes: aggTrades, bookDepth, bookTicker, indexPriceKlines, klines, markPriceKlines, metrics, premiumIndexKlines, trades. There is NO `liquidationSnapshot` prefix (empty listing) — [bucket listing](https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=data/futures/um/daily/liquidationSnapshot/)
- The repo README documents only aggTrades, klines, trades for futures; `metrics` and `bookDepth` exist in the bucket but are undocumented there — [binance-public-data README](https://github.com/binance/binance-public-data)
- `metrics` file columns (live probe of BTCUSDT-metrics-2024-01-15.zip): `create_time, symbol, sum_open_interest, sum_open_interest_value, count_toptrader_long_short_ratio, sum_toptrader_long_short_ratio, count_long_short_ratio, sum_taker_long_short_vol_ratio`; 288 rows/day (5-minute). BTCUSDT files start 2020-09-01; SOLUSDT and DOGEUSDT start 2021-12-01 — [BTCUSDT metrics listing](https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=data/futures/um/daily/metrics/BTCUSDT/&max-keys=3), [metrics file](https://data.binance.vision/data/futures/um/daily/metrics/BTCUSDT/BTCUSDT-metrics-2024-01-15.zip). A GitHub issue discusses the same metrics path/columns — [binance-public-data issue 211](https://github.com/binance/binance-public-data/issues/211)
- Caveat on file provenance: the BTCUSDT 2020-09 file objects show LastModified 2026-03-18, i.e. the archive was (re)generated in bulk then; whether early rows are true point-in-time snapshots or back-filled is not documented. This matters for causality checks. (Inference from the listing timestamps, see Inferences.)
- `bookDepth` (order-book depth snapshots) BTCUSDT starts 2023-01-01 — [bookDepth listing](https://s3-ap-northeast-1.amazonaws.com/data.binance.vision?delimiter=/&prefix=data/futures/um/daily/bookDepth/BTCUSDT/&max-keys=1)
- Live API retention: `/futures/data/openInterestHist`, `/futures/data/globalLongShortAccountRatio` and `/futures/data/basis` state "Only the data of the latest 30 days is available" (OI hist: "latest 1 month"), limit max 500, IP rate limit 1000 requests/5min; `/fapi/v1/fundingRate` limit max 1000; aggTrades only last 48h via API; klines limit 1500 — [Binance USDS-M docs](https://developers.binance.com/docs/derivatives/usds-margined-futures/market-data/rest-api/Open-Interest-Statistics). Live probe: a startTime older than 30 days is rejected with error -1130 — [openInterestHist](https://fapi.binance.com/futures/data/openInterestHist?symbol=BTCUSDT&period=1d&limit=5)
- Liquidations: the `/fapi/v1/allForceOrders` request returned a Binance HTML error page in my probe (region block or endpoint no longer served); I could not obtain data — [allForceOrders](https://fapi.binance.com/fapi/v1/allForceOrders?symbol=BTCUSDT&limit=2). Binance liquidation stream is websocket forward-only (general knowledge; not verified here).

**Deribit (public, no auth)**
- DVOL: `GET https://www.deribit.com/api/v2/public/get_volatility_index_data?currency=BTC&start_timestamp=..&end_timestamp=..&resolution=1D` (resolutions `1`, `60`, `3600`, `43200`, `1D`; OHLC rows; `continuation` returns the next end_timestamp to page backward; no max record count stated; currencies BTC, ETH, USDC, USDT, EURR) — [Deribit docs](https://docs.deribit.com/api-reference/market-data/public-get_volatility_index_data). Live probe, paging backward at 1D: 2008 daily candles back to 2021-03-24 (about 5.5 years) — [DVOL endpoint](https://www.deribit.com/api/v2/public/get_volatility_index_data?currency=BTC&start_timestamp=1400000000000&end_timestamp=1790000000000&resolution=1D)
- Options trades with implied vol: the archive host `https://history.deribit.com/api/v2/public/get_last_trades_by_currency_and_time?currency=BTC&kind=option&start_timestamp=..&end_timestamp=..` returned 2022-01 trades with `iv`, `mark_price`, `index_price`, direction; the main host returned an empty list for the same 2022 window, so older trades require history.deribit.com — [history.deribit.com probe](https://history.deribit.com/api/v2/public/get_last_trades_by_currency_and_time?currency=BTC&kind=option&start_timestamp=1640995200000&end_timestamp=1641081600000&count=2). Full historical option order books/Greeks are not provided free (general; not verified).
- Also live: `public/get_historical_volatility` (hourly realized vol, recent window) and `public/get_delivery_prices` (2632 records) — [get_historical_volatility](https://www.deribit.com/api/v2/public/get_historical_volatility?currency=BTC), [delivery prices](https://www.deribit.com/api/v2/public/get_delivery_prices?index_name=btc_usd&count=2)

**OKX / Bybit**
- OKX Rubik stats (live probes): `GET https://www.okx.com/api/v5/rubik/stat/contracts/open-interest-volume?ccy=BTC&period=1D` returns daily OI/volume; `.../long-short-account-ratio?ccy=BTC&period=1D` returned only 180 daily points (about 6 months, from 2026-04-12) — [OKX OI+volume](https://www.okx.com/api/v5/rubik/stat/contracts/open-interest-volume?ccy=BTC&period=1D), [OKX LSR](https://www.okx.com/api/v5/rubik/stat/contracts/long-short-account-ratio?ccy=BTC&period=1D)

**Polymarket (public, no auth)**
- CLOB price history: `GET https://clob.polymarket.com/prices-history?market=<asset/token id>&interval=max|all|1m|1w|1d|6h|1h&fidelity=<minutes, default 1>&startTs&endTs` returns `history: [{t, p}]`. The docs page states no depth limit and nothing about resolved markets — [Polymarket docs](https://docs.polymarket.com/developers/CLOB/timeseries). - Market discovery: Gamma API `GET https://gamma-api.polymarket.com/markets?closed=true&limit=..` returns question, start/end dates, and `clobTokenIds` (needed as the `market` parameter) — [Gamma markets](https://gamma-api.polymarket.com/markets?limit=1&closed=true&order=volume&ascending=false). Per-trade/wallet history is not covered by this endpoint (not tested).

**On-chain (free)**
- DefiLlama stablecoins: `GET https://stablecoins.llama.fi/stablecoincharts/all` live probe returned 3236 daily rows from 2017-11-29 with `totalCirculatingUSD` split by peg type (USD total ≈ $312.3bn at last row) — [DefiLlama stablecoin charts](https://stablecoins.llama.fi/stablecoincharts/all). Per-stablecoin series exist at sibling endpoints (not probed).
- blockchain.com charts API: `https://api.blockchain.info/charts/<name>?timespan=all&format=json&sampled=true` returned e.g. daily confirmed Bitcoin transactions from 2009 — [blockchain.info charts](https://api.blockchain.info/charts/n-transactions?timespan=all&format=json&sampled=true). I did not verify that an exchange-netflow chart exists there; exchange-labelled flows (CryptoQuant, Glassnode) are paid/limited per their docs — [CryptoQuant exchange flow guide](https://docs.cryptoquant.com/data-guide/exchange/exchange-in-outflow-and-netflow) (describes the metric; I did not verify free-tier limits).
- Dune free tier: not verified (no doc fetched).

### Inferences
- Forward-only list (cannot be backtested from free sources on day 1): liquidation events (Binance none, OKX recent only), Hyperliquid per-wallet positions and OI history (current snapshots only; S3 archive is requester-pays with no guaranteed completeness), OKX LSR beyond ~6 months, Binance LSR/OI via API beyond 30 days (but the bulk `metrics` files cover this).
- Binance `metrics` is the single richest free backfill (OI + three long/short ratios, 5-min, 2020-09/2021-12 onward), and is the natural test bed for OI/LSR signals without waiting for forward collection. Breadth is about 4-5 years for BTC and most large alts, but all in the crypto factor.
- The archive's LastModified of 2026-03-18 suggests bulk regeneration; the pre-registration should include a data-provenance check (e.g. compare a few days of 2026 metrics rows with live `/futures/data/*` values captured at the time) before treating early rows as point-in-time.
- Hyperliquid 1h bars only go back ~6 months, so any Hyperliquid replication at sub-daily frequency is effectively forward-collection too; daily candles and fundingHistory (paginated, 500/page) give about 3.4 years (from 2023-05).
- DVOL daily (2021-03 onward, about 5.5 years) plus Deribit option trades with IV (2022 onward verified) is enough for a volatility-premium study, but gives a short, single-asset (BTC/ETH) sample.

### Gaps
- Exact start date of Hyperliquid fundingHistory for BTC (probe began at my chosen startTime; first record 2023-05-12 for a 2023-05-01 query suggests launch-era start but not confirmed).
- Whether Hyperliquid S3 `asset_ctxs` and `l2Book` archives have usable coverage and what they cost per GB; no pricing/coverage fetched.
- Bybit and OKX historical depth beyond what the probes returned; Dune free-tier limits; free exchange-netflow sources; Polymarket depth limits for resolved crypto markets and wallet-level data.
- Binance liquidation history: could not reach `allForceOrders`; whether any bulk liquidation archive still exists is unconfirmed (bucket shows none).

## 2. What credible studies find about predictive power, signal by signal

### Takeaway
Across these signals, the best-supported predictive evidence is for (i) crypto carry/funding-basis predicting crashes (BIS WP 1087, not a simple return forecast), (ii) volatility rather than returns (implied-vol/VRP and flows relate more to volatility), and (iii) a handful of short-horizon flow results (USDT inflows, ETH exchange inflows) from one preprint. For several widely used signals — long/short ratios, whale positions on Hyperliquid, open interest, DVOL as a return signal, order-book imbalance in BTC, liquidations as reversal signals — I found no peer-reviewed out-of-sample test with effect sizes; most claims are vendor or blog assertions. Stablecoin-issuance evidence is contradictory (Griffin-Shams vs Wei vs Lyons).

### Cited Findings

**Funding / carry / basis**
- Schmeling, Schrimpf, Todorov, "Crypto carry" (BIS WP 1087; first April 2023, revised October 2025): carry on BTC/ETH averages above 10% annually, can reach up to 60%/yr; "a high crypto carry predicts future price crashes"; a rise in carry goes with a rise in the price of crash-risk insurance; interest-rate differentials explain very little. Drivers: trend-chasing small investors demanding leverage and limited arbitrage capital. The page gave no coefficients, horizons or sample period — [BIS WP 1087](https://www.bis.org/publ/work1087.htm)
- A 2025 review reports the carry trade used to be highly profitable but profitability compressed sharply from 2024 (annualized Sharpe 4.06 from 2024, negative in 2025) — [arXiv 2510.14435](https://arxiv.org/pdf/2510.14435) (as relayed by search snippet; I did not open the paper)
- He, Manela, Ross, von Wachter, "Fundamentals of Perpetual Futures": deviations from no-arbitrage perp prices are larger in crypto than in traditional currency markets, move together across currencies, shrink over time, and an implied arbitrage strategy earns high Sharpe ratios. Abstract only; sample not seen. This is carry/arbitrage, not directional forecasting — [arXiv 2212.06888](https://arxiv.org/abs/2212.06888)
- A 2019 BitMEX study reports a Granger-causal link between funding rates and the BTC perpetual and builds GARCH models to forecast funding; abstract only — [arXiv 1912.03270](https://www.arxiv.org/abs/1912.03270)

**Open interest**
- Journal evidence relates unexpected OI to volatility, not returns: Bitcoin volatility covaries negatively with unexpected futures OI and positively with unexpected volume over the long run (EGARCH; International Review of Financial Analysis 2023); a 2022 Finance Research Letters paper finds unexpected OI relates to volatility with opposite signs at short and medium horizons. Abstract-level only — [IDEAS: IRFA 86](https://ideas.repec.org/a/eee/finana/v86y2023ics1057521923000133.html), [IDEAS: FRL 47](https://ideas.repec.org/a/eee/finlet/v47y2022ipbs1544612322000903.html)
- The "OI rising with price confirms trend" rule is a practitioner heuristic quoted in a paper, not a tested result — [arXiv 2202.09845](https://arxiv.org/pdf/2202.09845)
- I found no peer-reviewed out-of-sample test that OI or funding changes predict BTC returns (search negative result).

**Long/short ratios (retail vs top-trader)**
- No peer-reviewed test of the Binance top-trader or global long/short ratio found. Claims such as "ratio >2.8 then BTC falls in 48h 71% of the time (avg -4.3%)" come from an unsourced blog with no methodology — [blog claim](https://sites.google.com/view/decentralised-news/home/longshort-ratio-analysis); a newsletter found that of the last five times Binance's ratio exceeded 3.0 only two coincided with local bottoms — [The Block](https://www.theblock.co/post/318747/btc-long-short-ratio-nears-critical-level-on-binance-hinting-at-potential-price-correction)
- Related academic evidence on positioning: Dunbar and Owusu-Amoako (2023) report net-short positioning of speculative retail traders is a significant determinant of crypto returns, robust to attention, uncertainty, sentiment and past-return controls (CFTC-style futures positioning, not Binance LSR) — [UNCFSU repository](https://digitalcommons.uncfsu.edu/college_business_economics/314)

**Liquidations**
- No peer-reviewed test that liquidation volume predicts reversals or returns. arXiv preprints (single author, unreviewed) study 7 BTC liquidation cascades 2022-2025: no pre-cascade early-warning rise in lag-1 autocorrelation (significant in 4 of 39 configurations); rolling variance rises but coincident with, not before, the cascade — [arXiv 2607.27070](https://arxiv.org/pdf/2607.27070). Same author, October 2025 crash: branching ratio ≈0.1-0.2 (subcritical) — [arXiv 2608.03616](https://arxiv.org/pdf/2608.03616)
- Descriptive: the 10 Oct 2025 event erased $9.89bn of leveraged positions in 14 hours, 70% of losses within 40 minutes, spreads widening from 0.02 to 26.43 bps (Amberdata, vendor analysis) — [Amberdata](https://blog.amberdata.io/how-3.21b-vanished-in-60-seconds-october-2025-crypto-crash-explained-through-7-charts). A Journal of FinTech and Digital Assets paper uses Hyperliquid's order-book archive to study two-regime liquidity recovery after that event (title/snippet only) — [JFDA 1(2)](https://journals.lincoln.ac.nz/index.php/JFDA/article/download/1395/965/3881)
- BIS WP 1087 links carry and liquidation/margin spikes to crash risk (see above) — [BIS WP 1087](https://www.bis.org/publ/work1087.htm)

**Options: implied vol, VRP, skew**
- Variance risk premium (descriptive): Deribit data July 2017-Dec 2022, squared BVIX 0.72 vs realized variance 0.58, VRP ≈0.14 vs about 2% for S&P 500; VRP 0.17 in low-vol cluster vs 0.12 in high-vol cluster. Source is a Substack summary without named authors; verify before use — [Harbourfront Quant](https://harbourfrontquant.substack.com/p/return-and-variance-risk-premia-in)
- Alexander and Imeraj, "The Bitcoin VIX and its Variance Risk Premium" (Journal of Alternative Investments 2020): builds 1-week to 3-month Bitcoin implied-vol indices from >7 million 15-minute Deribit prices, March 2019-March 2020; compares the VRP with equities, oil, gold, FX, Treasuries — [Sussex repository](https://sro.sussex.ac.uk/id/eprint/91094/)
- Almeida, Grith, Miftachov, Wang, "Risk Premia in the Bitcoin Market": conditional premia by volatility regime; low-vol regime has higher BVRP; not a forecasting regression — [arXiv 2410.15195](https://arxiv.org/html/2410.15195v2)
- Skew predicting returns: a 2026 SMU PhD dissertation (unreviewed) on daily Deribit data April 2021-Dec 2025 (1,723 obs) finds the 25-delta 90-day risk reversal significant at 1% in a 13-variable regression with Newey-West errors (t rises from 1.91 univariate to 3.73 with controls), butterfly t 2.13 to 2.34, concentrated in 30-180 day maturities, with the signal weakening after early 2024 (spot ETF approval); the sign was not stated in what I saw and results are in-sample — [SMU dissertation](https://ink.library.smu.edu.sg/etd_coll/887)
- Net option buying pressure on Deribit shows informed trading: regressions of returns and realized/implied vol on lagged option volume (hourly) — [arXiv 2109.02776](https://arxiv.org/pdf/2109.02776)
- DVOL/BVIV forecasting realized volatility: I found no academic test in search; only vendor/education pages and anecdotes (e.g. BVIV troughs in Aug 2023 and Feb 2024 followed within 2-3 months by spikes above 55; BVIV-price correlation -0.13) — [CryptoSlate](https://cryptoslate.com/record-compression-in-implied-volatility-sets-up-next-big-move-for-bitcoin/)

**On-chain flows: exchange netflows and stablecoins**
- Chi et al., "Return and Volatility Forecasting Using On-Chain Flows in Cryptocurrency Markets" (arXiv 2411.06327; 2017-2023; horizons 1-6 hours): ETH net inflows negatively predict ETH returns and volatility at all intraday intervals; USDT net inflows into exchanges positively predict BTC and ETH returns at multiple intervals; BTC net inflows generally do not predict BTC returns except at 4 hours but are negatively associated with BTC volatility. Abstract only: no effect sizes or out-of-sample results visible — [arXiv 2411.06327](https://arxiv.org/abs/2411.06327)
- Hoang and Baur (via Quantpedia summary): changes in exchange reserves negatively related to contemporaneous and future BTC returns; I did not read the paper — [Quantpedia](https://quantpedia.com/?p=15945)
- Practitioner claims (unverified methods): Ecoinometrics says each 10k BTC of monthly inflows typically accompanies a 4.3% return; Macro Hive says exchange-balance coefficients are negative and significant — [Ecoinometrics](https://ecoinometrics.substack.com/p/for-bitcoin-returns-flow-streaks), [Macro Hive](https://macrohive.com/hive-exclusives/do-flows-onto-crypto-exchanges-predict-bitcoin-price-moves)
- Stablecoin issuance: Griffin and Shams, "Is Bitcoin Really Untethered?" (Journal of Finance 2020, 75, 1913-1964; Bitcoin and Tether data March 2017-March 2018): Tether purchases are timed after market downturns and are followed by sizable Bitcoin price increases, attributable to one entity, clustering below round prices; Tether disputes the findings — [MIT Technology Review](https://www.technologyreview.com/2019/11/04/132066/one-bitcoin-whale-may-have-fueled-the-currencys-price-spike-in-2017/)
- Contradicting: Wei (2018) VAR on daily data finds Tether issuances do not impact subsequent Bitcoin returns (they affect trading volume); Lyons and Viswanath-Natraj (2020) find no systematic price effect; Ante, Fiedler, Strehle (2020) event study of 565 issuances >= $1m across 7 stablecoins, April 2019-March 2020, finds positive abnormal returns in the 24h around issuance (strongest for USDT) and that issuance follows prior-week downturns, with size not significant — [Blockchain Research Lab WP](https://www.blockchainresearchlab.org/wp-content/uploads/2020/05/The_Influence_of_Stablecoin_Issuances_on_Cryptocurrency_Markets_BRL_Working_Paper_No_11.pdf); [IDEAS: Wei, Economics Letters](https://ideas.repec.org/a/eee/ecolet/v171y2018icp19-22.html)
- 2026 Research Square preprint (not peer reviewed): daily data April 2020-March 2026, hidden Markov models; stablecoin volume growth positively associated with BTC returns in medium-volatility regimes, stablecoin transaction-count growth negatively; framed as a regime signal, not a linear predictor — [Research Square](https://www.researchsquare.com/article/rs-9715935/v1)
- Reverse causality: NY Fed work finds stablecoin flows respond to Bitcoin price moves (flight-to-safety dynamics) — [Fed in Print](https://fedinprint.org/item/fednls/99893); FTSE Russell reports stablecoin growth correlates with US M2 growth — [FTSE Russell](https://www.lseg.com/en/ftse-russell/research/stablecoins-effective-bridge-between-fiat-and-crypto-or-a-bridge-too-far). A CryptoQuant-based news piece claims supply growth precedes BTC rises (secondary, no formal test) — [CoinDesk](https://www.coindesk.com/record-stablecoin-supply-growth-doubles-8-billion/)

**Prediction markets (Polymarket)**
- Accuracy varies by domain: US election markets about 94-99% accurate; NBA about 66% five days out rising to 68% one hour before tip-off (secondary summary) — [casino.org summary](https://casino.org/blog/are-prediction-markets-accurate)
- Vanderbilt study (about 2,500 markets, final five weeks of the 2024 US election): Polymarket 67% right vs Kalshi 78% and PredictIt 93%; Kalshi disputes the metric (calibration vs hit rate) — [Yahoo Finance summary](https://finance.yahoo.com/news/polymarket-kalshi-reliable-not-quite-201417879.html)
- LBS/Yale working paper: 1.72 million accounts, 210,322 markets, about $13.76bn volume; only 3.14% of accounts are "skilled winners"; information is aggregated by an informed minority — [Bitcoin.com News](https://news.bitcoin.com/polymarket-study-finds-3-14-drive-accuracy/?rand=52384), [The Block](https://www.theblock.co/post/398902/skilled-polymarket-traders-are-a-3-minority-and-everyone-else-funds-their-gains-study)
- Good Judgment (commercial interest) found superforecasters scored 0.102 vs 0.126 for Polymarket on central-bank decisions — [Good Judgment](https://goodjudgment.substack.com/p/testing-polymarkets-most-accurate)
- I found no study testing whether Polymarket prices (including its crypto price-threshold markets) predict subsequent BTC/ETH returns or volatility.

**Order-book imbalance**
- Cont, Kukanov, Stoikov: order-flow imbalance linearly explains short-horizon price changes (equities, not crypto) — as cited in [search summary of arXiv 2506.05764 context](https://arxiv.org/pdf/2506.05764)
- Wang (2025, Chicago), Bybit 100 ms LOB snapshots, top-1 and top-5-level imbalance features: argues gains come from preprocessing and features rather than deeper networks; out-of-sample metrics not seen — [arXiv 2506.05764](https://arxiv.org/pdf/2506.05764)
- No Bitcoin-specific peer-reviewed out-of-sample study with costs found. Binance's free `bookDepth` starts 2023-01-01 for BTCUSDT (see Q1), but these signals live at milliseconds-to-seconds, where fees/latency dominate (inference).

**Hyperliquid whale / large-trader positions**
- No academic study found on whale positions' information content or returns. Available material is aggregate snapshots (e.g. whale long/short exposure about 50/50 in mid-2026 per Coinglass-citing news) and anecdotes — [KuCoin news flash](https://www.kucoin.com/news/flash/hyperliquid-whale-positions-reach-4-394b-with-50-02-longs-and-49-98-shorts)
- Related prediction-market evidence that a small informed minority drives price discovery (3.14% skilled accounts on Polymarket) is the only analogue found — [Bitcoin.com News](https://news.bitcoin.com/polymarket-study-finds-3-14-drive-accuracy/?rand=52384)

### Inferences
- Strength ranking by evidence quality (my judgment): carry-predicts-crash (peer-reviewed-track BIS paper, but a tail-risk/crash signal, not a tradable daily return forecast, and compressed since 2024) > volatility-side relations (OI vs vol, flows vs vol, VRP descriptive) > short-horizon flow results (single preprint, abstract only) > skew (single unreviewed dissertation, in-sample, fading after 2024) > everything else (anecdote/vendor).
- The pattern "signal relates to volatility more reliably than to returns" recurs (OI, BTC netflows, VRP regimes). For a repo that must add independent information, volatility/crash-risk targets (not directional returns) may be the better first test for OI, carry, DVOL and flows; this is also faster to evaluate.
- Several "positive" results are contemporaneous or reverse-causal (stablecoin flows follow price per NY Fed; Ante et al. show issuance follows downturns), so lagged, point-in-time tests are essential.
- Signals likely already priced/decayed: crypto carry (Sharpe collapsed after 2024), skew (weakened after ETFs), simple LSR contrarian rules (unsupported). Tether-issuance timing is contested and, if Griffin-Shams was right, reflects a 2017-18 manipulation regime that may not persist.
- Funding carry's non-replication in this repo with consistent-venue funding is consistent with the literature's finding that carry's edge is in arbitrage/crash prediction and compressed recently.

- Sign of the risk-reversal coefficient in the SMU dissertation.
- Any academic test of: Binance LSR/top-trader ratio; liquidation-volume reversal; DVOL forecasting realized vol or returns; Polymarket-to-crypto-return predictiveness; Hyperliquid whale positioning; BTC order-book imbalance out-of-sample with costs; Glassnode/Kaiko/Amberdata free reports with stated methodology (not retrieved).
- Authorship/identity of the Substack VRP summary study (Harbourfront Quant) not verified.

## 3. Which signals have out-of-sample support, which are spurious or already priced

### Takeaway
No signal in this list has clean, independent, peer-reviewed out-of-sample evidence of tradable return prediction after costs. The nearest to credible are crash/volatility predictors (carry, OI-vs-vol, flow-vs-vol) and a few short-horizon flow results; the most popular retail signals (long/short ratios, whale positioning, liquidation counters, DVOL as an entry timer) are untested in the literature and mostly supported by vendor marketing. Contested or decayed: Tether-issuance timing, carry after 2024, skew after early 2024.

### Cited Findings
- Decay: carry Sharpe collapsed from historic highs to 4.06 (2024 onward) and negative in 2025 — [arXiv 2510.14435](https://arxiv.org/pdf/2510.14435) (snippet); perp-vs-spot deviations "shrink over time" — [arXiv 2212.06888](https://arxiv.org/abs/2212.06888); skew signal weakened after early 2024 — [SMU dissertation](https://ink.library.smu.edu.sg/etd_coll/887)
- Event heterogeneity: no early-warning variable is invariant across seven BTC liquidation cascades; variance rises coincident with, not before, cascades — [arXiv 2607.27070](https://arxiv.org/pdf/2607.27070)
- Mixed/contradictory: Tether issuance (Griffin-Shams positive vs Wei and Lyons null; Ante et al. short-window abnormal returns) — see Q2 sources
- Short-horizon valuation-type predictors are weak: a valuation-ratio study found no short-run (1-week, 30-day) BTC predictive power, improving at longer horizons — [search result listing](https://dergipark.org.tr/en/pub/jbef/article/1982320) (snippet-level)
- Practitioner consensus that LSR works only with funding and OI context is stated by Mudrex (retail education, not evidence) — [Mudrex](https://mudrex.com/learn/binance-ratio-avoid-bull-bear-traps/)

### Inferences
- Candidate tests that satisfy the repo's constraints (free data, independent information, shorter time-to-answer), ordered by my judgment:
  1. Binance `metrics` OI/LSR/taker-ratio versus next-day realized volatility and crash indicators (5-year backfill, daily scoring, but within the crypto factor; pre-register on assets chosen without looking at P&L).
  2. DVOL minus trailing realized vol (VRP proxy) versus next-month realized vol / short-vol payoff proxy (2021-03 onward, daily).
  3. DefiLlama stablecoin supply growth as a lagged, slow, low-turnover regime variable (daily, 2017 onward) — expect regime-dependence per the 2026 preprint and reverse causality per the NY Fed.
  4. Polymarket crypto-threshold market prices versus subsequent realized outcomes: information independent of price, but short free history and no existing evidence; forward-collect cheaply.
  5. OKX liquidation flow (already forward-only in repo): literature gives no prior, so keep as descriptive.
- Low-priority/avoid: Hyperliquid whale-following (no history, no evidence, cannot backtest), order-book imbalance (ms-scale, costs), Tether-mint timing (contested, manipulation-era sample).
- These all remain inside the crypto factor; none adds breadth of assets, so they raise information type, not independence from market beta. Evidence-rate rule: new per-cell diagnostics on DON8/EMA8/VOL8 or the same 10 coins should be avoided.

### Gaps
- No free dataset found that provides independent non-crypto assets for these signal types (out of scope here).
- Could not confirm Glassnode/Kaiko/Amberdata free reports with stated methodology that test these signals; vendor posts found had no methodology.
- Did not verify whether Binance metrics rows pre-2023 are point-in-time (see Q1 inference).
