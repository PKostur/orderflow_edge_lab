## Boundaries and safe use

The implementation uses **opt-in successor APIs/CLIs**. It does not silently repair v1 APIs by changing frozen numeric results. Existing watch starts, symbols, cost models, thresholds, scoring and review rules remain intact. Operational replay retention is aligned from seven to the already-declared fourteen days. The PR guards apply only to this engineering branch prefix; they do not disable the scheduled or manual collection/forward studies on their normal paths.

Callers must separately freeze applicable future policies and supply qualified provenance/coverage before using successor evidence. Independently retained immutable storage, restore/retrieval rehearsal, real provider completeness, instrument/firm-term facts, exclusive append anchoring and future evaluation inputs are not inferred from local hashes.
