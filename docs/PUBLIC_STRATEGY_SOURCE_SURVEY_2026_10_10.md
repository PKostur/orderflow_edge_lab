# Public strategy and bot implementation survey — 2026-10-10

**Scope:** 25 directly inspected, publicly accessible source-code implementations across Freqtrade, Hummingbot, Jesse, Backtrader, vn.py, NautilusTrader, LEAN and TradingView/Pine. This is a **source-code survey**, not a validation study or a claim that any public strategy makes money. Code was inspected for mechanics; the external projects were not installed, traded or independently backtested. All links are to upstream source files, and branch URLs may change after this inspection. **No upstream strategy code has been copied into this repository.**

**Source quality:** A code example establishes that a particular rule or order workflow was published, not that fills, returns, risk controls, robustness, or execution latency are realistic. Project-level license and last-push metadata were checked on GitHub; this does not verify individual file provenance or grant rights to relicense upstream code. Strategy-level performance evidence was **not independently established for any row**. Existing local frozen strategies and all their observations remain unchanged.

## Evidence and transfer decision

- **Verified:** source paths existed and mechanics above were read from the named files; GitHub project license/maintenance metadata was inspected. The two Pine file-level license situations are intentionally distinguished.
- **Not verified:** profitable performance, market-data authenticity, executable fill assumptions, lookahead freedom, robustness across venues, complete operational safety, or adequacy of the original authors' optimization methods.
- **Do not transplant:** upstream code under incompatible licenses, reported historical profits, optimized thresholds, hypothetical free fills, leverage, or paper/live order connectors.
- **Transferable patterns:** causal signal timestamps, independent engine replication, queue/fill modeling, per-leg fees, order-state recovery, time/session awareness, explicit risk/exit logic, and source-to-evidence lineage.
- **Implementation choice:** three original, simple, **spot long-only** price/volume experiments in [the separate shadow specification](../config/public_strategy_shadow_v1.json), intentionally not rewiring existing frozen Universal or DV2 studies. More complex two-leg and L2 ideas remain research hypotheses until their source and execution requirements can be met.

This catalog is a development-time inspection ledger. Merely collecting 25 examples increases the trial universe; it does not increase the count of independent positive strategy confirmations.
